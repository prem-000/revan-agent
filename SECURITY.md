# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.x     | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

We take the security of Multi-Agent Research System seriously. If you believe
you have found a security vulnerability, please report it to us as described
below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them via email to maintainers. You should receive
a response within 48 hours. If for some reason you do not, please follow up via
email to ensure we received your original message.

Please include the following information in your report:

* Type of issue (e.g., buffer overflow, SQL injection, cross-site scripting, etc.)
* Full paths of source file(s) related to the manifestation of the issue
* The location of the affected source code (tag/branch/commit or direct URL)
* Any special configuration required to reproduce the issue
* Step-by-step instructions to reproduce the issue
* Proof-of-concept or exploit code (if possible)
* Impact of the issue, including how an attacker might exploit it

This information will help us triage your report more quickly.

## Preferred Languages

We prefer all communications to be in English.

## Policy

We follow the principle of coordinated disclosure:

1. The reporter reports the vulnerability privately.
2. We work with the reporter to understand and validate the issue.
3. We develop and test a fix.
4. We release the fix and publicly acknowledge the reporter's contribution (if they wish to be credited).

We aim to resolve confirmed vulnerabilities within 90 days of initial report.
